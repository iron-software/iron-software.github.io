    Class EciMode

    Controls whether a UTF-8 Extended Channel Interpretation (ECI) header is written into 2D barcode symbols (DataMatrix, QR, Aztec, PDF417).

    An ECI header tells a scanner that the encoded bytes should be interpreted as UTF-8. It is only meaningful when the data contains non-ASCII characters; for pure ASCII data it adds redundant codewords that can enlarge the symbol and confuse legacy scanners that do not understand ECI.

    Set the library-wide default through DefaultEciMode, which applies to every 2D format. The DataMatrixWriter overloads additionally accept a per-call value to override the default for a single DataMatrix.

    public sealed class EciMode : Enum

    EciMode controls whether a UTF-8 Extended Channel Interpretation header is written into 2D barcode symbols (DataMatrix, QR, Aztec, PDF417). Auto is the default: the header is added only when non-ASCII characters are present. ForceUtf8 always writes the ECI header, and Off suppresses it entirely for maximum compatibility with legacy scanners. Set the library-wide default via DefaultEciMode, or pass a per-call value to DataMatrixWriter overloads to override it for a single symbol.

    BarcodeWriter.CreateBarcode("Héllo", BarcodeEncoding.QRCode, eciMode: EciMode.Auto);

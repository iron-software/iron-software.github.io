    Class IronPdfProductException

    Represents errors that occur during IronPDF execution.

    public class IronPdfProductException : Exception

    The IronPdfProductException class represents errors that occur during IronPDF execution.

    Part of the IronPdf.Exceptions namespace and inheriting from Exception, it surfaces when the corresponding call cannot complete, typically from bad input, an unsupported configuration, or an error in the native library.

    Inspect the Message and InnerException properties to diagnose what went wrong.

    For common platform-specific causes, consult the IronPDF troubleshooting guides.

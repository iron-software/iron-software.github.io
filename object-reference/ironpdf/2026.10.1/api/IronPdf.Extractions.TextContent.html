    TextContent matters when an application needs to configure or invoke text extraction from C# code. The class encapsulates the related options and behavior in a single object that is set up once and reused across render or processing calls. Typical scenarios include batch generation pipelines, templated document workflows, and integration with existing C# document services.

    To use TextContent, instantiate or obtain it from the relevant entry point in the IronPDF C# API. Key properties include PageTexts, RawText. Assign options or invoke methods on the instance to configure or perform the operation. The access PDF DOM object covers typical usage in C# end to end.

var instance = new TextContent();
var current = instance.PageTexts;
// Read or assign other properties such as RawText, PageTexts
instance.GetText();

    RawText

    Raw text from all pages concatenated

    Contains the text content of all pages in the document, concatenated together.

    When table extraction is enabled, this contains only text located outside detected tables.

    When table extraction is disabled, this contains all text including text inside tables.

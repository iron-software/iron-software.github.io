    Class TextExtractionMode

    Text extraction modes

    Determines how text is extracted from PDF documents.

    Inheritance
    System.Object
    TextExtractionMode
    Namespace: IronPdf.Extractions
    Assembly: IronPdf.dll
    Syntax
    public sealed class TextExtractionMode : Enum

    The TextExtractionMode enumeration in IronPDF picks the algorithm PdfExtractor uses to read characters from a PDF page.

    Part of the IronPdf.Extractions namespace, the 2 members are PositionBased (coordinates reconstruct columns and reading order) and Stream (content-stream order, faster but layout-blind).

    See Extract Text & Images for the extraction surface that consumes this setting.

    Fields

    PositionBased

    Extracts text positioned top-to-bottom, left-to-right.

    Best for single-column documents and standard layouts.

    Uses visual positioning to determine reading order.

    Class FontWeight

    FontWeight
    Namespace: PdfToSvg
    Assembly: IronPdf.dll
    Syntax
    public sealed class FontWeight : Enum

    FontWeight controls the stroke weight applied to fonts during PDF-to-SVG conversion in IronPDF. Default and Normal (aliased as Regular) are the right starting points for body text. The scale runs from Hairline and Thin at the lightest end through Light, ExtraLight, and UltraLight, up to Medium, SemiBold (aliased as DemiBold), Bold, ExtraBold, UltraBold, Heavy, and Black for progressively heavier strokes. See the IronPDF SVG conversion docs for usage context.

    var options = new SvgOptions { FontWeight = FontWeight.Bold };

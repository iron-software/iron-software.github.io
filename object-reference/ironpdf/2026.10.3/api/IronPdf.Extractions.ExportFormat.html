    Class ExportFormat

    Supported export formats

    Defines the file formats available for exporting extracted data.

    Inheritance
    System.Object
    ExportFormat
    Namespace: IronPdf.Extractions
    Assembly: IronPdf.dll
    Syntax
    public sealed class ExportFormat : Enum

    The ExportFormat enumeration in IronPDF declares the 5 file targets that ExportManager and ExportConfiguration accept when serializing extracted PDF content.

    Part of the IronPdf.Extractions namespace, it covers Csv, Json, and Xml for structured downstream pipelines, plus Html and Txt for human-readable output.

    See Extract Text & Images for the PdfExtractor workflow these formats plug into.

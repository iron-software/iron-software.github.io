    Type Name Description
    System.String fontName

    PDF font name as it appears in the document's /DR /Font dictionary
    System.Byte[] fontData

    Raw TrueType/OpenType bytes; pass null or empty for name-only mode (the font must already be embedded in the document)
    System.Boolean forceEmbed

    When true, embed fontData even if a font with the same name and usable glyph data is already present. Has no effect in name-only mode.

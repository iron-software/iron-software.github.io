    BitonalMode

    Bitonal (1-bit CCITT Group 4) compression mode for scanned/black-and-white content. When not Off, eligible images are thresholded to pure black/white and CCITT Group 4 encoded, which is dramatically smaller than JPEG on scanned text (and sharper). The bitonal result is only kept when it is actually smaller than the original; otherwise the JPEG path is used.

    options.BitonalMode = BitonalCompressionMode.Off;    // Default: normal JPEG pipeline
options.BitonalMode = BitonalCompressionMode.Force;  // Convert every eligible 8-bit image

    Note: BitonalResolutionDpi defaults to null and the bitonal pass then falls back to TargetImageDpi, which defaults to 150. So setting only BitonalMode resamples a 300 DPI scan to 150 DPI before thresholding. Set BitonalResolutionDpi explicitly, or set TargetImageDpi to null, to threshold at the source resolution.

    Declaration

    Property Value
    Type Description
    BitonalCompressionMode
    Remarks

    Only applies to images the pipeline can rasterize; already-bitonal images are left untouched.

    BitonalResolutionDpi

    Target DPI for bitonal images when BitonalMode is enabled. Images whose effective resolution exceeds this are downsampled before thresholding.

    Precedence: this value wins when set. When it is null the bitonal path falls back to TargetImageDpi, so a bitonal pass is not silently left at full resolution when only TargetImageDpi is set. When both are null the source resolution is kept. Has no effect when BitonalMode is Off.

    BitonalThreshold

    Luminance threshold (1-255) used to split pixels into black/white when BitonalMode is enabled. null (default) auto-computes an optimal per-image threshold using Otsu's method (recommended for varied scans). Set an explicit value only when you need a fixed, deterministic cutoff. A value of 0, or one outside 1-255, falls back to the auto threshold, because a cutoff of 0 would make every pixel white.

    JpegQuality

    JPEG quality used when re-encoding images during optimization (1-100). When set, automatically enables image optimization.

    Recommended settings:

    options.JpegQuality = null;  // No image re-encoding (default)
options.JpegQuality = 95;    // Archival â€” minimal artifacts
options.JpegQuality = 85;    // High quality
options.JpegQuality = 70;    // Balanced â€” good for general use
options.JpegQuality = 50;    // Web/email â€” visible artifacts, smaller files

    Declaration
    public Nullable<int> JpegQuality { get; set; }
    Property Value
    Type Description
    System.Nullable<System.Int32>

    Quality level from 1 (minimum) to 100 (maximum), or null (default) to leave images untouched.
    Remarks

    Where the re-encoding happens depends on TargetImageDpi:

    • TargetImageDpi set (default 150): Each image is downsampled and re-encoded at this JPEG quality. optimizeImages is skipped to avoid double JPEG encoding.
    • TargetImageDpi = null: optimizeImages re-encodes images at this JPEG quality without changing pixel dimensions.

    The two paths can produce visibly different artifacts at the same quality value. If you need predictable output, decide up-front whether you want resolution reduction or quality-only reduction and set TargetImageDpi accordingly.

    TargetImageDpi

    Target DPI for image downsampling during advanced compression. Images whose effective rendered DPI exceeds this value are box-filter downsampled to TargetImageDpi before re-encoding.

    Recommended values:

    options.TargetImageDpi = 300;   // Print quality â€” lossless to the eye at normal viewing distance
options.TargetImageDpi = 200;   // Crisp on high-DPI / retina screens
options.TargetImageDpi = 150;   // Default â€” best size/quality balance for screen + email
options.TargetImageDpi = 96;    // Aggressive â€” soft text but still readable
options.TargetImageDpi = null;  // Disabled â€” preserve original resolution (largest file)

    Images that are already bitonal (1 bit per component, e.g. CCITT/JBIG2 scans) are exempt: they are left untouched rather than rasterized and re-encoded, because re-encoding a 1-bit image as JPEG enlarges and degrades it. As a result TargetImageDpi does not downsample already-bitonal images.

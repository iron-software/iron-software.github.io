    Class ExternalSigner

    Signs PDF documents with a key held by an external signing service, such as Azure Key Vault or a cloud HSM, through an IExternalSignatureProvider. The private key never leaves the service.

    Use with the IronPdf signing methods that accept an IHsmSigner. Set TimeStampUrl to embed an RFC 3161 timestamp.

    The signing certificate and chain are read from the provider once, when the signer is created. Create a new signer after the certificate or key changes. Signing fails if the certificate is expired or not yet valid.

    The LibraryPath, UserPin and TokenLabel properties do not apply to this signer.

    Parameters
    Type Name Description
    IExternalSignatureProvider provider

    Supplies the signing certificate and signs hashes.
    SignatureHashAlgorithms hashAlgorithm

    The signature hash algorithm. SHA256, SHA384 and SHA512 are supported. Services that tie the hash to the key size, such as Azure Key Vault ES384 and ES512, need SHA384 for P-384 keys and SHA512 for P-521 keys.
    System.String internalName

    Optional signature field name. A unique name is generated when null.

    Interface IExternalSignatureProvider

    Supplies the certificate and the signing operation for an ExternalSigner. Implement this to sign with a key held by an external service, such as Azure Key Vault or a cloud HSM. The private key is never required.

    SignHash(Byte[], SignatureHashAlgorithms)

    Signs a hash with the private key that belongs to SigningCertificate. Called once per signature on the calling thread, and may block.

    Declaration

    Parameters
    Type Name Description
    System.Byte[] hash

    The hash to sign.
    SignatureHashAlgorithms hashAlgorithm

    The algorithm used to compute hash, as set on the ExternalSigner.
    Returns
    Type Description
    System.Byte[]

    For RSA keys, a complete RSASSA-PKCS1-v1_5 signature. The provider applies the DigestInfo encoding for hashAlgorithm, as Azure Key Vault RS256 and RSA.SignHash with PKCS#1 padding do. For ECDSA keys, the signature as raw r||s or DER-encoded.

    Class AdvancedCompressionOptions

    Configuration for the advanced compression pipeline.

    Inheritance
    System.Object
    AdvancedCompressionOptions
    Namespace: IronPdf
    Assembly: IronPdf.dll
    Syntax
    public class AdvancedCompressionOptions : Object

    AdvancedCompressionOptions configures IronPDF's current-recommended compression pipeline, consumed by PdfDocument.CompressAndSaveAs(string, AdvancedCompressionOptions) and the static byte-array and stream overloads. A parameterless constructor gives you an instance whose twelve properties cover image downsampling, JPEG re-encoding, Flate stream tuning, object-stream layout, and structural cleanup. It is the broader successor to the older CompressionOptions configuration.

    Use AdvancedCompressionOptions for any new compression code in IronPDF, since PdfDocument.Compress(CompressionOptions) is marked deprecated and slated for removal. Typical scenarios are post-render size reduction for Chrome-engine output with embedded photos, batch shrinking of scan-heavy PDFs whose embedded bitmaps exceed display resolution, in-memory compression of byte arrays for HTTP responses or cloud-function output, and producing email-attachment-sized copies of report documents without persisting the source PDF.

    The twelve properties fall into three groups. For image re-encoding and downsampling, TargetImageDpi (Nullable<int>, default 150) is the headline knob that downsamples images above the threshold and dominates size reduction for photo-heavy or Chrome-rendered PDFs, while JpegQuality (Nullable<int>, 1-100, default null) sets the re-encoding quality and OptimizeImagesMinArea, OptimizeImagesMinWidth, and OptimizeImagesMinHeight exclude small assets like logos and signatures from re-encoding. HighQualityImageSubsampling (default true) selects 4:4:4 chroma subsampling versus 4:1:1. For stream compression, CompressStreams (default true), CompressionLevel (0-9, default 9), RecompressFlate (default true), DecodeGeneralizedStreams (default true), and CoalesceContents (default true) control how content streams are deflated and merged, while ObjectStreams of type ObjectStreamMode (default Generate) controls the cross-reference layout. For structural cleanup, RemoveUnreferencedResources (default true) drops orphan objects and RemoveStructureTree strips the logical-layout tree at the cost of accessibility. The PDF compression how-to shows where each of these settings earns its keep on a real document.

    using IronPdf;

PdfDocument pdf = PdfDocument.FromFile("input.pdf");

var options = new AdvancedCompressionOptions
{
    TargetImageDpi              = 150,    // default; downsample images above 150 dpi
    JpegQuality                 = 75,     // re-encode images at quality 75
    HighQualityImageSubsampling = true,   // 4:4:4 chroma for better color
    CompressionLevel            = 9,      // maximum zlib level
    CompressStreams             = true,
    RecompressFlate             = true,
    ObjectStreams               = ObjectStreamMode.Generate,
    RemoveUnreferencedResources = true,
    RemoveStructureTree         = false   // preserve text selection and accessibility
};

pdf.CompressAndSaveAs("compressed.pdf", options);

    The PDF compression example reports the realized file-size deltas for these settings. When migrating off the deprecated Compress(CompressionOptions) path, the PDF compression how-to names the current and legacy APIs side by side.

    Type Description
    System.Boolean

    true to decode generalized filters before re-encoding (default); false to leave them as the input encoded them.
    Remarks

    Lossless â€” only generalized filters are touched. Specialized (RunLengthDecode) and image filters (DCTDecode, CCITTFaxDecode, JBIG2Decode, JPXDecode) are not affected by this flag.

    JpegQuality

    JPEG quality used when re-encoding images during optimization (1-100). When set, automatically enables image optimization.

    Recommended settings:

    options.JpegQuality = null;  // No image re-encoding (default)
options.JpegQuality = 95;    // Archival â€” minimal artifacts
options.JpegQuality = 85;    // High quality
options.JpegQuality = 70;    // Balanced â€” good for general use
options.JpegQuality = 50;    // Web/email â€” visible artifacts, smaller files

    Declaration
    public Nullable<int> JpegQuality { get; set; }
    Property Value
    Type Description
    System.Nullable<System.Int32>

    Quality level from 1 (minimum) to 100 (maximum), or null (default) to leave images untouched.
    Remarks

    Where the re-encoding happens depends on TargetImageDpi:

    • TargetImageDpi set (default 150): Each image is downsampled and re-encoded at this JPEG quality. optimizeImages is skipped to avoid double JPEG encoding.
    • TargetImageDpi = null: optimizeImages re-encodes images at this JPEG quality without changing pixel dimensions.

    The two paths can produce visibly different artifacts at the same quality value. If you need predictable output, decide up-front whether you want resolution reduction or quality-only reduction and set TargetImageDpi accordingly.

    Class BarcodeStamper

    Stamps barcodes and QR codes onto PDF pages for tracking, URLs, and data encoding. Supports Code128, Code39, and QR Code formats with customizable dimensions.

    Example - Add barcodes to PDFs:

    var pdf = PdfDocument.FromFile("invoice.pdf");

    // QR code for payment URL (top-right corner):
var paymentQR = new BarcodeStamper(
"https://pay.example.com/inv-12345",
BarcodeEncoding.QRCode)
{
Width = 100,
Height = 100,
HorizontalAlignment = HorizontalAlignment.Right,
VerticalAlignment = VerticalAlignment.Top,
VerticalOffset = new Length(20, MeasurementUnit.Pixel)
};
pdf.ApplyStamp(paymentQR);
    

    // Product barcode (bottom of page):
var productCode = new BarcodeStamper(
"SKU-2024-0012345",
BarcodeEncoding.Code128)
{
Width = 200,
Height = 50,
VerticalAlignment = VerticalAlignment.Bottom
};
pdf.ApplyStamp(productCode);
    

    pdf.SaveAs("invoice_with_barcodes.pdf");

    public class BarcodeStamper : Stamper

    Overlaying a machine-readable barcode or QR code onto a PDF through PdfDocument.ApplyStamp is the job of BarcodeStamper. A configured BarcodeStamper carries the data to encode, the barcode symbology, and the rendered pixel dimensions, then is handed to ApplyStamp on a PdfDocument for the actual write. It shares the placement, opacity, rotation, and click-through properties of its sibling stampers TextStamper, HtmlStamper, and ImageStamper.

    Barcode stamping covers the overlay tasks where the payload has to be scannable: shipping and tracking numbers on packing slips, SKU and inventory codes on pick sheets, asset tags on equipment manuals, QR codes that deep-link to payment portals on invoices, and serial numbers on warranty forms. The class wraps each of these as a reusable configuration object, so a pipeline that stamps many documents constructs the BarcodeStamper once and reuses it across ApplyStamp calls against a single page, a list of pages, or every page.

    Construct a BarcodeStamper with (string Value, BarcodeEncoding BarcodeType) and let Width and Height default to 250 pixels each, or use the four-argument constructor (string Value, BarcodeEncoding BarcodeType, int Width, int Height) to size the bars at construction time. Value is the string to encode, BarcodeType selects between BarcodeEncoding.QRCode (the default), BarcodeEncoding.Code128, and BarcodeEncoding.Code39, and Width and Height are integer pixel sizes. The corner-placement controls most barcodes need, HorizontalAlignment, VerticalAlignment, HorizontalOffset, VerticalOffset, Opacity, and the IsStampBehindContent layering switch, all come from the Stamper base. The inherited Hyperlink property attaches a clickthrough URL on top of the stamped code, useful for QR codes that should also respond to a tap inside a PDF reader. Once configured, hand the instance to one of the ApplyStamp overloads on PdfDocument. The stamp text and image how-to has a dedicated barcode-stamping section.

    using IronPdf;
using IronPdf.Editing;

var pdf = PdfDocument.FromFile("invoice.pdf");

// Construct a clickable payment QR, place it top-right, then apply and save.
var paymentQR = new BarcodeStamper(
    "https://pay.example.com/inv-12345", BarcodeEncoding.QRCode, 120, 120)
{
    HorizontalAlignment = HorizontalAlignment.Right,
    VerticalAlignment = VerticalAlignment.Top,
    Hyperlink = "https://pay.example.com/inv-12345"
};

// ApplyStamp also has overloads for page targeting and async pipelines:
//   pdf.ApplyStamp(paymentQR, 0);            // first page only
//   await pdf.ApplyStampAsync(paymentQR);    // async pipeline
pdf.ApplyStamp(paymentQR).SaveAs("invoice-stamped.pdf");

    For barcode formats that BarcodeEncoding does not cover, the Add Barcodes in HTML to PDF example shows how to fall back to rendering a barcode through HTML or generating an image with IronBarcode and overlaying it with ImageStamper. To see how the placement, sizing, and layering properties carry over from the base class, reach for the stamp text and image how-to.

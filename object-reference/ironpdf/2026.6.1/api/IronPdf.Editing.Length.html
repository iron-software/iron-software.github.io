    Class Length

    Represents a value with a specific measurement unit.

    Inheritance
    System.Object
    Length
    Namespace: IronPdf.Editing
    Assembly: IronPdf.dll
    Syntax
    public class Length : Object

    Length carries a numeric measurement together with the unit it is expressed in and converts it between units. It is the return type for any IronPDF API that hands back a measured dimension, most prominently the extension method that converts a PdfPaperSize enum value into its width and height.

    Length matters whenever code needs to read a dimension out of IronPDF and then reuse the same value in a different unit. The standard pattern is to call PdfPaperSizeConverter.ToMillimeters(PdfPaperSize.A4), receive a (Length, Length) tuple for width and height, then call .ToInch() or .ToPixel() on each element to feed the value into print logic, viewport math, or a custom layout calculation. Constructing a Length directly is also supported when an application needs to pin a fixed measurement at startup and convert from it on demand.

    A Length instance holds three pieces of state. The Value property is the raw double. The Unit property is a MeasurementUnit field constant (MeasurementUnit.Centimeter, Inch, Millimeter, Percentage, Pixel, or Points). The DPI property is the integer dots-per-inch used when converting to or from Pixel, defaulting to 96. Five conversion methods read the instance and return a double in the requested unit: ToCentimeter, ToInch, ToMillimeter, ToPixel, and ToPoints. Each conversion method accepts an optional refValue argument that is required only when Unit is MeasurementUnit.Percentage, since a percentage has no absolute size until a reference dimension is supplied. The custom paper size how-to has a worked example of the ToMillimeters extension feeding Length values into a custom-dimensioned render call.

    using IronPdf;
using IronPdf.Editing;
using IronPdf.Rendering;

// Canonical entry point: get Length values from a standard paper size
(Length width, Length height) = PdfPaperSizeConverter.ToMillimeters(PdfPaperSize.A4);

double widthInInches = width.ToInch();
double heightInPixels = height.ToPixel();
double heightInPoints = height.ToPoints();

// Direct construction for a fixed measurement
Length margin = new Length(value: 12.7, unit: MeasurementUnit.Millimeter, dpi: 96);
double marginInInches = margin.ToInch();

    For dimensions expressed as a percentage, pass a reference value to the conversion method so the result has an absolute size. The custom margins how-to covers the related millimeter-based margin configuration where the dimensions are taken as plain double values rather than Length instances.

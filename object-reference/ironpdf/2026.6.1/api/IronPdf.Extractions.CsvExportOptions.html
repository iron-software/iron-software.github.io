    Class CsvExportOptions

    Configuration options for CSV exports

    Provides control over delimiters, quoting, and cell formatting specific to CSV format.

    ------------------------------------------------

    Usage:

{
CsvDelimiter = ";",
CsvQuoteStrings = true,
CsvNewlineReplacement = " ",
IncludeHeaders = true
};

    Use CsvExportOptions to control how ExportManager.ExportTable and ExportManager.ExportTables write extracted PDF tables to comma-separated value files. It exposes a parameterless constructor plus three CSV-format properties that control delimiter character, embedded-newline handling, and quoting, on top of the four row-shape properties inherited from the base class.

    Use CsvExportOptions when an extraction pipeline calls ExportManager against a TableObject or a list of tables and the output target is a spreadsheet, an analytics warehouse loader, or any tool that expects RFC 4180-style CSV. Typical cases include invoice line-item extraction, financial statement table capture, and scheduled batch jobs that turn tabular PDF reports into ingestible flat files. Pick CsvExportOptions when the receiving system reads CSV; pick HtmlExportOptions, JsonExportOptions, TxtExportOptions, or XmlExportOptions for those respective output formats. The disambiguation FAQ below covers the criteria.

    The constructor takes no arguments, and configuration is by property assignment. CsvDelimiter is the cell separator character with default ","; set it to ";" for European spreadsheet locales or "\t" for tab-separated output. CsvQuoteStrings (default true) wraps string cells in quotation marks so embedded delimiters and whitespace survive round-tripping; turning it off produces smaller files at the cost of fragility. CsvNewlineReplacement (default " ") is the substitution applied inside cells that contain line breaks in the source PDF, preventing those breaks from being interpreted as row terminators by the consumer. Four inherited properties from ExportOptionsBase shape the rows themselves: IncludeHeaders decides whether the first row carries column labels, IncludeEmptyRows retains or drops blank rows from the extracted table, SpanMode controls how merged-cell spans are flattened, and TextEncoding sets the byte encoding of the written file (defaults to UTF-8 for cross-platform consumers).

    using IronPdf;
using IronPdf.Extractions;
using System.Text;

var extractor = new PdfExtractor();
PdfExtractionResult result = extractor.Extract("invoice.pdf");

var options = new CsvExportOptions
{
    CsvDelimiter          = ",",
    CsvQuoteStrings       = true,
    CsvNewlineReplacement = " ",
    IncludeHeaders        = true,
    IncludeEmptyRows      = false,
    TextEncoding          = Encoding.UTF8
};

// Export a single extracted table to a CSV file.
ExportManager.ExportTable(result.Tables[0], "line-items.csv", options);

    The TableObject inputs to this pipeline come from the table-extraction step in the extract text and images how-to. The full export surface, including the ExportConfiguration.TableOptions slot where a CsvExportOptions instance is consumed by ExportManager.ExportResult, is documented on the ExportManager reference page.

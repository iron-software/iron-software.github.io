    Class JsonExportOptions

    Configuration options for JSON exports

    Currently inherits all options from ExportOptionsBase.

    Serializing extracted PDF tables as JSON runs through JsonExportOptions: passing one to the IronPDF extraction pipeline tells it to write a TableObject or a PdfExtractionResult as JSON. It declares a single parameterless constructor, and all configurable settings come from the base class, which is the same pattern shared by CsvExportOptions, HtmlExportOptions, TxtExportOptions, and XmlExportOptions.

    Use JsonExportOptions when extracted tabular data needs to travel to a downstream API, a JavaScript front end, a NoSQL store, or any consumer that expects structured records rather than flat text. JSON is the right export choice for machine-to-machine handoff and for analytics pipelines that prefer typed values to delimited strings. Pick a sibling instead when the consumer is a spreadsheet (CsvExportOptions), a browser preview (HtmlExportOptions), a plain-text log (TxtExportOptions), or a schema-validated document store (XmlExportOptions).

    JsonExportOptions is constructed with new JsonExportOptions() and passed to one of three static entry points on IronPdf.Extractions.ExportManager. The instance carries four inherited properties that shape the output: IncludeHeaders (default true) emits a header row for the JSON records, IncludeEmptyRows (default false) skips blank rows during serialization, SpanMode (default SpanHandlingMode.Repeat) controls how a cell that spans multiple rows or columns is materialized, and TextEncoding (default UTF8) sets the byte encoding of the written file. The runtime selects the JSON writer by inspecting the concrete options type, so passing a JsonExportOptions instance to any overload that accepts ExportOptionsBase produces JSON output.

    using System.Collections.Generic;
using IronPdf;
using IronPdf.Extractions;

PdfDocument pdf = PdfDocument.FromFile("invoice.pdf");
PdfExtractionResult result = new PdfExtractor().Extract(pdf);
List<TableObject> tables = result.Tables;

var jsonOptions = new JsonExportOptions
{
    IncludeHeaders   = true,
    IncludeEmptyRows = false,
    SpanMode         = SpanHandlingMode.Repeat
};

ExportManager.ExportTables(tables, "tables.json", jsonOptions);

    The tables consumed here are produced by the workflow in the extract text and images how-to. For lower-level reading of unstructured content, the parse PDFs in C# guide complements the table-export path that JsonExportOptions participates in.

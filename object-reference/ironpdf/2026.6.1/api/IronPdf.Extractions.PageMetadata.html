    Class PageMetadata

    Per-page metadata

    Contains information about a specific page, such as page number, table count, and word count.

    Inheritance
    System.Object
    PageMetadata
    Namespace: IronPdf.Extractions
    Assembly: IronPdf.dll
    Syntax
    public class PageMetadata : Object

    Page-level facts about a single page after extracting a PDF with IronPDF live on PageMetadata. Each instance carries four read-only facts about a single page: which page it is, how big the page is, how many tables were found on it, and how many words were found on it. Instances are produced by PdfExtractor.Extract, exposed through DocumentMetadata.PageMetadata as a dictionary keyed by 1-based page number.

    PageMetadata is useful any time downstream logic has to branch on page-level facts rather than on the document as a whole. Typical scenarios include reporting on which pages of a long contract actually contain tabular data, validating that an invoice page contains a non-zero word count before sending it to an LLM, and computing margins or content area from PageBounds before stamping or cropping. The class is a result DTO: every property is get-only, and code reads from instances rather than assigning to them.

    PageMetadata exposes four members. PageNumber returns the 1-based page index used as the dictionary key on the parent DocumentMetadata.PageMetadata. PageBounds returns a PdfRectangle describing the physical dimensions of the page in PDF user-space units, suitable for computing aspect ratio or content area. TableCount returns the number of tables IronPDF's extractor detected on this page, useful for skipping pages with no tabular content. WordCount returns the number of words extracted from this page, useful as a cheap density signal for OCR fallback decisions. The canonical access pattern is to call PdfExtractor.Extract, read .Metadata.PageMetadata, and look up the page of interest. A worked extraction run appears in the extract text and images how-to.

    using IronPdf;
using IronPdf.Extractions;

PdfExtractionResult result = PdfExtractor.Extract("report.pdf");

// PageMetadata for page 1
PageMetadata page1 = result.Metadata.PageMetadata[1];

int    pageNumber = page1.PageNumber;   // 1
double width      = page1.PageBounds.Width;
double height     = page1.PageBounds.Height;
int    tables     = page1.TableCount;
int    words      = page1.WordCount;
    // Iterate every page and report content density
PdfExtractionResult result = PdfExtractor.Extract("report.pdf");

foreach (KeyValuePair<int, PageMetadata> entry in result.Metadata.PageMetadata)
{
    PageMetadata page = entry.Value;
    Console.WriteLine($"Page {page.PageNumber}: {page.WordCount} words, {page.TableCount} tables");
}

    The document-level counterpart DocumentMetadata carries TotalPages and a roll-up TableCount and owns the Dictionary<int, PageMetadata> from which these per-page instances are read. For the broader extraction workflow that produces both classes, see the PdfExtractor static class.

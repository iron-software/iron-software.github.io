    Class TableRow

    Represents a table row

    Contains a collection of cells that make up a row in a table.

    Inheritance
    System.Object
    TableRow
    Namespace: IronPdf.Extractions
    Assembly: IronPdf.dll
    Syntax
    public class TableRow : Object

    When you walk one row inside a recognized table extracted from a PDF, TableRow provides the row's cell list, column indexer, row index within the parent table, cell count, and row height as a single read-only container. Each instance corresponds to one row of one TableObject produced by the PdfExtractor pipeline and is normally obtained from that parent rather than constructed directly.

    TableRow is the type a caller works with when iterating the structured rows of an extracted table: walking the line items of an invoice, pulling each row of a quarterly financial table, or feeding row-shaped records into an ETL pipeline that loads PDF tables into a database or a spreadsheet. Every property is get-only, so a TableRow returned from extraction reflects the recognizer's view of that row and is safe to share across worker threads that only read.

    To obtain TableRow instances, call PdfExtractor.Extract(pdfPath) to receive a PdfExtractionResult, read its Tables property to enumerate each TableObject, then iterate either DataRows (typed as List<TableRow>) for body rows or HeaderRows for column headers. TableObject.GetRow(int rowIndex) returns a single row and throws ArgumentOutOfRangeException on a bad index. The headline members are the row payload first: Cells (typed as List<TableCell>) for the full ordered cell list, the Item[Int32] indexer for direct column access where row[0] returns the first TableCell, and GetCellText(int columnIndex) for the plain string at one column. The locator and metric members are RowIndex (0-based position inside the parent table), CellCount (number of cells in the row), and Height (row height in PDF points). The extract text and images how-to places row iteration inside an end-to-end extraction example.

    using IronPdf;
using IronPdf.Extractions;
using System.Collections.Generic;

PdfExtractionResult result = PdfExtractor.Extract("invoice.pdf");

foreach (TableObject table in result.Tables)
{
    foreach (TableRow row in table.DataRows)
    {
        // Indexer returns the TableCell at the given 0-based column.
        TableCell firstCell = row[0];

        // GetCellText returns just the string at the given column.
        string sku = row.GetCellText(0);
        string description = row.GetCellText(1);

        System.Console.WriteLine(
            $"Row {row.RowIndex}: {row.CellCount} cells, " +
            $"height {row.Height} pt -> {sku} | {description}");
    }
}

    If row structure is irrelevant and only the text matters, reach for the ExtractAllText and ExtractTextFromPage facade shown in the parse PDFs in C# how-to.

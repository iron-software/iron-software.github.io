    Class PdfFontCollection

    Observable collection of fonts

    Inheritance
    System.Object
    PdfFontCollection
    Namespace: IronPdf.Fonts
    Assembly: IronPdf.dll
    Syntax
    public class PdfFontCollection : ObservableCollection<PdfFont>

    PdfFontCollection holds the fonts referenced inside an IronPdf.PdfDocument and lets callers inspect, add, or embed them. It carries the full standard collection surface (Count, integer indexer, foreach, CollectionChanged) plus a small set of font-specific members layered on top. Every PdfFont a caller works with comes out of this collection, and every font added to a document goes in through it.

    The class is reached through one property: PdfDocument.Fonts returns a PdfFontCollection. Application code typically opens a PDF, walks the collection to inspect which fonts the document references, adds missing fonts from byte arrays or from the 14 standard PDF font names, and then calls Embed() on individual PdfFont instances to guarantee consistent rendering on machines that lack the original font. Typical scenarios include preparing documents for PDF/A compliance, replacing display fonts in incoming third-party PDFs, and inventorying fonts across batch document-processing pipelines.

    The font-specific members on PdfFontCollection are deliberately small. The string indexer this[string name] returns the first PdfFont whose name matches (or null if absent). Find(string name, bool skipSubsetFonts = false) performs the same lookup with an option to skip subset-embedded fonts. Two Add overloads cover the two ways a font enters the document: Add(string Name) accepts one of the 14 standard PDF font names (Courier, Helvetica, Times, Symbol, Dingbats and their style variants) and returns a PdfFont without embedding; Add(byte[] Data) accepts raw font-file bytes and returns a PdfFont ready for an Embed() call. For the add-find-embed sequence in context, see the manage fonts how-to.

    using IronPdf;
using IronPdf.Fonts;
using System.IO;

PdfDocument pdf = PdfDocument.FromFile("report.pdf");
PdfFontCollection fonts = pdf.Fonts;

// Inspect every font the document references.
foreach (PdfFont font in fonts)
{
    System.Console.WriteLine($"{font.Name} (embedded: {font.IsEmbedded})");
}

// Add a standard PDF font by name (no embedding required).
PdfFont helvetica = fonts.Add("Helvetica");

// Add a custom font from disk and embed it for cross-platform display.
byte[] fontBytes = File.ReadAllBytes("Roboto-Regular.ttf");
PdfFont roboto = fonts.Add(fontBytes);
roboto.Embed();

// Look an existing font up by name through the indexer or Find.
PdfFont arial = fonts["Arial"];
PdfFont symbol = fonts.Find("Symbol", skipSubsetFonts: true);

pdf.SaveAs("report-with-fonts.pdf");

    A different problem is getting web fonts to load before render time: the web and icon fonts how-to handles @font-face and WaitFor.AllFontsLoaded, and the fonts troubleshooting guide addresses missing-glyph and embedding edge cases.

    Class PdfMetaData

    A class defining PDF file MetaData.

    Allows File MetaData to be read and set including: Authors, File Dates, Keywords, Title and Subject

    Implemented in IronPdf.MetaData.

    Inheritance
    System.Object
    PdfMetaData
    Namespace: IronPdf.MetaData
    Assembly: IronPdf.dll
    Syntax
    public class PdfMetaData : Object

    The standard PDF document information fields, title, author, subject, keywords, and dates, are stamped and read through PdfMetaData on a PdfDocument in IronPDF. It is obtained through the PdfDocument.MetaData property rather than constructed directly. Each property maps to one of the PDF specification's document information entries, so changes made through PdfMetaData propagate to the saved file and appear in any PDF reader's document properties dialog.

    The class is reached on every workflow that needs to stamp identity, ownership, or searchability information into a generated or modified PDF. Document management systems set Title, Author, and Subject so files surface correctly in SharePoint, search indexes, and operating-system previewers. Compliance pipelines record Creator and Producer for audit trails. Archival workflows write CreationDate and ModifiedDate for chronology. The PDF metadata how-to shows the read-and-stamp idiom on a rendered document.

    Identification strings on the class are Title, Author, Subject, Keywords, Creator, and Producer, each a string getter/setter. Date fields are CreationDate and ModifiedDate, both DateTime in Local Time; call ToUniversalTime() for UTC. Application-defined fields live under the CustomProperties property, which returns a PdfCustomMetadataProperties indexable by key. For bulk operations, GetMetaDataDictionary() returns the current snapshot, Keys() lists available keys, RemoveMetaDataKey(string) clears a single key, and SetMetaDataDictionary(Dictionary<string, string>) overwrites the whole set in one call (the docfx remarks recommend this dictionary form for Docker and gRPC deployments). The canonical idiom is to render or load a PdfDocument, assign to pdf.MetaData.*, and save.

    using IronPdf;
using System;

var renderer = new ChromePdfRenderer();
using PdfDocument pdf = renderer.RenderHtmlAsPdf("<h1>Quarterly Report</h1>");

pdf.MetaData.Title        = "Q4 Financial Report";
pdf.MetaData.Author       = "Finance Team";
pdf.MetaData.Subject      = "Quarterly financial results";
pdf.MetaData.Keywords     = "finance, quarterly, 2026";
pdf.MetaData.Creator      = "Reporting Service";
pdf.MetaData.Producer     = "IronPDF";
pdf.MetaData.CreationDate = DateTime.Now;
pdf.MetaData.ModifiedDate = DateTime.Now;

// Application-defined fields use CustomProperties (PdfCustomMetadataProperties).
pdf.MetaData.CustomProperties.Add("DocumentId", "DOC-2026-Q4-0001");

pdf.SaveAs("q4-report.pdf");

    For follow-on workflows, the metadata how-to covers reading existing values and the custom-property surface, and the metadata visibility troubleshooting note explains how reader software, file-system previewers, and PDF security settings interact when metadata appears blank or hidden.

    Class PdfAttachment

    Represents a file attachment embedded within a PDF document. Provides access to attachment metadata and binary data for extraction or modification.

    PDF attachments are complete files stored within the PDF container. They appear as paperclip icons in PDF readers and can contain any file type (spreadsheets, images, documents, etc.).

    Example - Extract attachment to disk:

    var pdf = PdfDocument.FromFile("invoice_with_receipt.pdf");
foreach (var attachment in pdf.Attachments)
{
    Console.WriteLine($"Found: {attachment.Name} at index {attachment.Index}");
    File.WriteAllBytes(attachment.Name, attachment.Data);
}

    PdfAttachment is what you receive for each file embedded inside an IronPdf.PdfDocument when you read or add attachments. It surfaces the three pieces of information a caller needs in order to identify or extract an attached file: its filename, its raw bytes, and its position inside the document's attachment collection. Attachments appear as paperclip icons in PDF readers and can hold any binary payload such as spreadsheets, images, archives, or other PDFs.

    The class is the value type that flows out of every read or write on PdfDocument.Attachments (typed as PdfAttachmentCollection). PdfAttachmentCollection.AddAttachment(string, byte[]) returns a PdfAttachment. The collection indexer returns one. The collection implements IEnumerable<PdfAttachment>, so a foreach yields one per attached file. Typical scenarios include extracting embedded receipts from incoming invoices, replacing an outdated supplementary file while keeping its filename intact, and inventorying attachments in batch document-processing pipelines.

    There is no public constructor; instances are always obtained from a PdfDocument. The headline members are Name (the filename stored in the PDF, get-only, including the extension) and Data (the raw byte[] of the file, with both get and set so the content can be overwritten in place). Index reports the zero-based position inside PdfAttachmentCollection and may shift between calls because attachments are sorted alphabetically on every mutation. For the full add/read/remove cycle, see the add and remove attachments how-to.

    using IronPdf;
using System.IO;

// Add an attachment and keep the returned PdfAttachment for later use.
PdfDocument pdf = PdfDocument.FromFile("invoice.pdf");
byte[] receiptBytes = File.ReadAllBytes("receipt.xlsx");
PdfAttachment added = pdf.Attachments.AddAttachment("receipt.xlsx", receiptBytes);

// Read every attachment back out: Name drives the on-disk filename, Data is the payload.
foreach (PdfAttachment attachment in pdf.Attachments)
{
    File.WriteAllBytes(attachment.Name, attachment.Data);
}

// Replace the bytes of an existing attachment while preserving its Name.
PdfAttachment first = pdf.Attachments[0];
first.Data = File.ReadAllBytes("updated-receipt.xlsx");
pdf.SaveAs("invoice-with-receipts.pdf");

    For the inverse case, the add attachment to PDF example walks through the minimal embedding shape, and the same add and remove attachments how-to covers RemoveAttachment for cleanup paths.

    Properties

    Data

    Gets or sets the raw binary data of the attachment. Read to extract, write to replace content while preserving the filename.

    Example - Extract and modify:

    // Extract attachment data:
byte[] data = attachment.Data;
File.WriteAllBytes($"extracted_{attachment.Name}", data);

    // Replace attachment content:
attachment.Data = File.ReadAllBytes("updated_receipt.pdf");
pdf.SaveAs("invoice_updated.pdf");

    Declaration
    public byte[] Data { get; set; }
    Property Value
    Type Description
    System.Byte[]

    The complete binary content of the attached file.
    Remarks

    Reading this property retrieves data from the PDF. For large attachments, consider caching the result if accessed multiple times.

    Index

    Gets the zero-based index of this attachment within the PDF document. Index may change if attachments are added or removed (alphabetically sorted).

    Name

    Gets the filename of this attachment as stored in the PDF document. Typically includes file extension (e.g., "receipt.pdf", "data.xlsx").

    Use this name when saving extracted attachments to preserve original filenames.

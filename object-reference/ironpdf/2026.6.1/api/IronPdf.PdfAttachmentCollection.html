    Class PdfAttachmentCollection

    Manages the collection of file attachments embedded in a PDF document. Supports adding, removing, and iterating through attachments.

    Access this collection via Attachments property.

    Example - Manage attachments:

    var pdf = PdfDocument.FromFile("document.pdf");

    // Add attachment:
byte[] excelData = File.ReadAllBytes("report.xlsx");
pdf.Attachments.AddAttachment("Q4_Report.xlsx", excelData);
    

    // List all attachments:
foreach (var att in pdf.Attachments)
Console.WriteLine($"{att.Index}: {att.Name}");
    

    // Remove first attachment:
pdf.Attachments.RemoveAttachment(pdf.Attachments[0]);
    

    pdf.SaveAs("modified.pdf");

    PdfAttachmentCollection adds, reads, enumerates, and removes the supporting files embedded inside a generated or loaded PDF. The collection supports four operations on the attached files inside a PDF: adding a new file, retrieving one by zero-based index, enumerating every attachment, and removing a specific one. The collection is automatically sorted alphabetically by attachment name on every mutation, so any cached integer position can shift after an add or remove call.

    Application code reaches the collection through PdfDocument.Attachments (a get-only property typed as PdfAttachmentCollection); there is no public constructor. Typical scenarios include attaching supporting Excel reports or receipt files to generated invoices, extracting embedded payloads from incoming PDFs, replacing an outdated supplementary file while keeping the document otherwise intact, and inventorying every attachment during batch document-processing.

    The headline method is AddAttachment(string name, byte[] data), which embeds a file and returns the newly created PdfAttachment for further use, such as reading its data back or passing it to a later removal call. The integer indexer this[int index] retrieves one attachment by position and throws ArgumentOutOfRangeException on invalid input. GetEnumerator() powers foreach over PdfAttachment items. RemoveAttachment(PdfAttachment attachment) deletes an attachment by reference, obtained from either the indexer or enumeration. Add, list, and remove are demonstrated step by step in the add and remove attachments how-to, and the add attachment to PDF example provides a runnable embedding snippet.

    using IronPdf;
using System.IO;

// Obtain the PdfAttachmentCollection through PdfDocument.Attachments.
PdfDocument pdf = PdfDocument.FromFile("invoice.pdf");
PdfAttachmentCollection attachments = pdf.Attachments;

// Add a new attachment; the returned PdfAttachment is the same instance the collection now holds.
byte[] receiptBytes = File.ReadAllBytes("receipt.xlsx");
PdfAttachment added = attachments.AddAttachment("receipt.xlsx", receiptBytes);

// Retrieve by zero-based indexer, then enumerate every attachment.
PdfAttachment first = attachments[0];
foreach (PdfAttachment attachment in attachments)
{
    File.WriteAllBytes(attachment.Name, attachment.Data);
}

pdf.SaveAs("invoice-with-receipts.pdf");
    // Remove a specific attachment by reference; alphabetical sort means remaining indexes may shift.
PdfAttachment target = pdf.Attachments[0];
pdf.Attachments.RemoveAttachment(target);
pdf.SaveAs("invoice-trimmed.pdf");

    For the canonical lifecycle including RemoveAttachment patterns and PDF/A-3 ZUGFeRD invoice attachments, see the add and remove attachments how-to again, paired with the add attachment example.

    Methods

    AddAttachment(String, Byte[])

    Embeds a file as an attachment within the PDF document. The attachment appears as a paperclip icon in PDF readers and can be extracted by users.

    Example - Attach supporting files:

    // Attach Excel report:
byte[] excelData = File.ReadAllBytes("financials.xlsx");
pdf.Attachments.AddAttachment("Q4_Financials.xlsx", excelData);

    // Attach multiple files:
foreach (var file in Directory.GetFiles("receipts"))
{
var data = File.ReadAllBytes(file);
pdf.Attachments.AddAttachment(Path.GetFileName(file), data);
}

    RemoveAttachment(PdfAttachment)

    Removes the specified attachment from the PDF document permanently.

    Example - Remove sensitive attachments:

    // Remove specific attachment by reference:
var pdf = PdfDocument.FromFile("document.pdf");
var sensitiveFile = pdf.Attachments.FirstOrDefault(
    a => a.Name.Contains("confidential"));
if (sensitiveFile != null)
    pdf.Attachments.RemoveAttachment(sensitiveFile);

    // Remove all attachments:
while (pdf.Attachments.Any())
pdf.Attachments.RemoveAttachment(pdf.Attachments[0]);
    

    pdf.SaveAs("cleaned.pdf");

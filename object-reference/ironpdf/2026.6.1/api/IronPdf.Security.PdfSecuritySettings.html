    Class PdfSecuritySettings

    Enterprise-grade PDF security: pdf.SecuritySettings.MakePdfDocumentReadOnly("owner123") Control passwords, 128-bit encryption, permissions for print/copy/edit. Essential for legal, financial, and government documents. Used via PdfDocument.SecuritySettings property.

    Inheritance
    System.Object
    PdfClientAccessor
    PdfSecuritySettings
    Namespace: IronPdf.Security
    Assembly: IronPdf.dll
    Syntax
    public class PdfSecuritySettings : PdfClientAccessor

    Reach for PdfSecuritySettings to protect a single PDF document with encryption, passwords, and permissions, working from the instance obtained through a PdfDocument's read-only SecuritySettings property. The class covers the four facets of PDF protection: user and owner passwords with 128-bit encryption, content extraction permissions (copy, paste, accessibility), document interaction permissions (edits, form data, annotations), and printing rights.

    Use PdfSecuritySettings to protect PDF output for compliance, archival, and distribution workflows. Typical scenarios include locking generated invoices and contracts so end users can view and print but cannot edit or extract text, requiring a password to open confidential reports, generating read-only versions of long-form documents for external review, and removing protection from previously encrypted PDFs after authenticated processing. The settings persist with the saved PDF, so they apply to any viewer that honors the PDF specification.

    Configuration follows the pdf.SecuritySettings.{Property} = value idiom, applied to an open PdfDocument before saving. Password and encryption properties are OwnerPassword and UserPassword (assigning either enables 128-bit encryption). Boolean permission flags are AllowUserAnnotations, AllowUserCopyPasteContent, AllowUserCopyPasteContentForAccessibility, and AllowUserFormData. The two graded permissions are AllowUserEdits (takes a PdfEditSecurity value: EditAll, EditPages, or NoEdit) and AllowUserPrinting (takes a PdfPrintSecurity value: FullPrintRights, PrintLowQuality, or NoPrint). Two convenience methods cover common end states: MakePdfDocumentReadOnly(string ownerPassword) applies a strict read-only policy in one call, and RemovePasswordsAndEncryption(bool removeSignatures = true) strips all protection. Every permission flag except printing requires OwnerPassword to be set to a non-empty value before the restriction takes effect. The PDF passwords and permissions how-to demonstrates each property in a worked example.

    using IronPdf;
using IronPdf.Security;

using var pdf = PdfDocument.FromFile("report.pdf");

// Passwords and 128-bit encryption (OwnerPassword unlocks the permission flags)
pdf.SecuritySettings.OwnerPassword = "admin456";
pdf.SecuritySettings.UserPassword  = "read123";

// Content extraction permissions
pdf.SecuritySettings.AllowUserCopyPasteContent                 = false;
pdf.SecuritySettings.AllowUserCopyPasteContentForAccessibility = true;
pdf.SecuritySettings.AllowUserAnnotations                      = false;
pdf.SecuritySettings.AllowUserFormData                         = false;

// Graded permissions: edits and printing
pdf.SecuritySettings.AllowUserEdits    = PdfEditSecurity.NoEdit;
pdf.SecuritySettings.AllowUserPrinting = PdfPrintSecurity.PrintLowQuality;

pdf.SaveAs("report-protected.pdf");

    For deeper coverage, the PDF encryption tutorial explains 128-bit encryption in C#. The passwords, security, and metadata examples page lists worked code for each property. To strip protection from existing files, see the encryption and decryption examples page.

    If AllowUserAnnotations is set false, the OwnerPassword must be set for the security measure to take effect.

    AllowUserEdits

    Gets or sets the permissions for users edit the PDF document. The features to edit the document depends entirely on the PDF client software used by the end user.

    If editing rights are restricted, then the OwnerPassword must be set for the security measure to take effect.

    Declaration
    public PdfEditSecurity AllowUserEdits { get; set; }
    Property Value
    Type Description
    PdfEditSecurity

    The PdfEditSecurity value for user edit security.

    AllowUserFormData

    Gets or sets the permissions for users to fill-in (enter data into) forms in the PDF document.

    If AllowUserFormData is set false, the OwnerPassword must be set for the security measure to take effect.

    Note. If you want to make the form readonly in Adobe Acrobat Reader please call MakePdfDocumentReadOnly(String) method or set AllowUserEdits to NoEdit and set OwnerPassword.

    OwnerPassword

    Sets the owner password and enables 128Bit encryption of PDF content. An owner password is one used to enable and disable all other security settings.

    OwnerPassword must be set to a non empty string value for AllowUserCopyPasteContent, AllowUserAnnotations, AllowUserFormData,s AllowUserPrinting and AllowUserEdits to be restricted.

    RemovePasswordsAndEncryption(Boolean)

    Removes all user and owner password security for a PDF document. Also disables content encryption.

    Content is encrypted at 128 bit. Copy and paste of content is disallowed. Annotations and form editing are disabled.

    Remove all digital signatures from the PDF document. (Recommended, since they will become invalidated anyway.)

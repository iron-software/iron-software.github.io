    Class PdfSignatureImage

    PDF digital signature image

    Inheritance
    System.Object
    PdfSignatureImage
    Namespace: IronPdf.Signing
    Assembly: IronPdf.dll
    Syntax
    public class PdfSignatureImage : Object

    The visible stamp on a signed PDF page (a logo, scanned signature, or seal shown alongside the cryptographic credential that authenticates it) is carried by PdfSignatureImage. It exposes three constructors that accept an AnyBitmap, a byte[], or a file path, and stores three settable properties for the bitmap itself, the zero-based target page, and the placement rectangle. An instance is assigned to the SignatureImage property of a PdfSignature and then written to the document by PdfDocument.Sign.

    Reach for PdfSignatureImage whenever a signed document needs a visual mark beside the cryptographic signature: a company logo on a countersigned contract, a scanned handwritten signature on an invoice, or a notary stamp on a legal exhibit. The class is the carrier shape for that image; the surrounding PdfSignature carries the certificate, signing reason, location, contact, and timestamp. The two travel together through one Sign call and the visible image is embedded inside the signed revision, so any change to the page after signing invalidates both.

    Pick a constructor by where the image lives. The (string path, int pageIndex, Rectangle rectangle) overload reads a PNG, JPEG, GIF, BMP, TIFF, or WebP file from disk. The (byte[] bytes, int page_index, Rectangle rectangle) overload accepts raw image bytes from a database or HTTP response. The (AnyBitmap bitmap, int page_index, Rectangle rectangle) overload accepts an already-decoded AnyBitmap from IronSoftware.Drawing, suiting images generated in memory or shared with IronOCR or IronBarCode. PageIndex is zero-based, and Rectangle is the IronSoftware.Drawing.Rectangle value type constructed as Rectangle(x, y, width, height) in PDF points (1 inch is 72 points), with the origin at the bottom-left of the page. The convenience methods LoadSignatureImageFromFile and LoadSignatureImageFromStream on PdfSignature are wrappers that build a PdfSignatureImage and assign it for you.

    using IronPdf;
using IronPdf.Signing;
using IronSoftware.Drawing;

var signature = new PdfSignature("IronSoftware.pfx", "123456")
{
    SigningReason = "Approved for release",
    SignatureDate = DateTime.Now
};

// Build the visible stamp: Rectangle is x, y, width, height in PDF points with the
// origin at the bottom-left. Byte[] and AnyBitmap constructors exist for off-disk images.
var stampArea = new Rectangle(350, 750, 200, 100);
signature.SignatureImage = new PdfSignatureImage("assets/handwritten.png", 0, stampArea);

// PdfDocument.Sign writes the cryptographic signature and the visible image together.
using var pdf = PdfDocument.FromFile("invoice.pdf");
pdf.Sign(signature);
pdf.SaveAs("invoice-signed.pdf");

    For the signing workflow that adds timestamping, signing reason, and permissions around the visible stamp, see the PDF signing how-to. A runnable project is on the digitally sign a PDF example page. The same SignatureImage surface applies when the certificate is held in a hardware module, as the HSM signing how-to shows.

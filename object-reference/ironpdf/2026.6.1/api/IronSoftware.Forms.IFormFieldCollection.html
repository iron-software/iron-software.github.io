    Interface IFormFieldCollection

    Form field collection list

    Namespace: IronSoftware.Forms
    Assembly: IronPdf.dll
    Syntax
    public interface IFormFieldCollection : IList<IFormField>, ICollection<IFormField>, IEnumerable<IFormField>, IEnumerable

    IFormFieldCollection is what you reach through the Form property on a PdfDocument whenever C# code needs to read, fill, remove, or audit the fillable form fields on a single document. Every form field on a loaded document is accessible by integer index, by enumeration, or by name, so application code rarely constructs the collection and instead consumes the instance the document already exposes.

    Filling a job application, auto-populating an invoice template, removing signature fields before archiving, and rendering audits that walk every field on the document are all expressed as lookups or iterations over this collection. Because the contract is shared between the interface and its concrete implementor, code written against IFormFieldCollection continues to work if the document type evolves.

    The headline members fall into two groups. The three IronPDF-specific methods are FindFormField, which resolves a field by fully-qualified name and falls back to partial matches when no exact match exists, SetFormFont, which embeds a document-wide font used for subsequent fills, and DisableFormFontFallback, which suppresses the automatic fallback embed for non-ASCII values. The inherited IList<IFormField> surface adds the integer indexer, Count, Add, Remove, Clear, Contains, and IndexOf for direct collection manipulation. The concrete implementor is FormFieldCollection in the IronSoftware namespace, an ObservableCollection<IFormField> subclass. Looking up and iterating fields through pdf.Form is demonstrated in the fill and edit PDF forms how-to.

    using IronPdf;
using IronSoftware.Forms;

PdfDocument pdf = PdfDocument.FromFile("application.pdf");

// pdf.Form is the IFormFieldCollection for this document.
IFormFieldCollection fields = pdf.Form;

// Lookup by name returns IFormField. Partial matches are tried if the
// fully-qualified name does not match exactly.
IFormField nameField = fields.FindFormField("FullName");
if (nameField != null && !nameField.ReadOnly)
{
    nameField.Value = "Jane Doe";
}

// Enumeration uses the inherited IList<IFormField> surface.
System.Console.WriteLine($"field count: {fields.Count}");
foreach (IFormField field in fields)
{
    System.Console.WriteLine($"{field.FullName} = {field.Value}");
}

pdf.SaveAs("application-filled.pdf");

    For per-field manipulation through the same collection, see IFormField. For building a fillable PDF before working with this collection, the create PDF forms how-to is the entry point.

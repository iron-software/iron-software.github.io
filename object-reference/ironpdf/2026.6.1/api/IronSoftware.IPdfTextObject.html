    Interface IPdfTextObject

    Text object from a PDF document

    Inherited Members
    IPdfDocumentObject.Client
    Namespace: IronSoftware
    Assembly: IronPdf.dll
    Syntax
    public interface IPdfTextObject : IPdfDocumentObject, IPdfDocumentObject, IDocumentObject, IDocumentTextObject, IBoundedPdfDocumentObject, IBounded, ITransformable, IColored, ICloneable, IJsonSerializable

    IPdfTextObject is what you receive for one text run when you enumerate PdfPage.TextChunks or PdfPage.Lines in IronPDF, supplying the uniform member surface that lets helpers audit, classify, or transform PDF text without binding to a concrete class. The interface itself adds no declarations; everything you call on it is aggregated from the inherited contracts named in its declaration.

    Two concrete classes implement IPdfTextObject in the IronPDF API. The base implementor is IronSoftware.TextObject, returned for one text run when enumerating PdfPage.TextChunks. The derived implementor is IronPdf.Pages.LineTextObject, returned for one visual line when enumerating PdfPage.Lines (the line-grouped view of the same underlying chunks). Both collections are typed as IPdfTextObjectCollection (element type TextObject), so a polymorphic consumer receives the interface and may operate on either concrete shape without a cast.

    The members that carry everyday use of this contract group into four buckets. Content and identity arrives from IDocumentTextObject: Contents (the literal characters), PageIndex, and FontObject. Geometry arrives from IBoundedPdfDocumentObject and ITransformable: BoundingBox (the primary RectangleF read shape), the read-only Matrix, nullable X and Y, Scale, Translate, and Rotation. Typography arrives alongside content: FontSize, IsBold, and IsItalic. Color and render arrive from IColored: FillColor, StrokeColor, and RenderMode. Two methods sit at the top level of the contract: Clone() from ICloneable and ToJson() from IJsonSerializable. The plumbing handle Client (an IPdfClient) comes in from IPdfDocumentObject. For the surrounding read-side workflow, the extract text and images how-to has the worked example.

    using IronPdf;
using IronPdf.Pages;
using IronSoftware;

// Polymorphic consumer: accepts IPdfTextObject so it works for both
// TextObject (from PdfPage.TextChunks) and LineTextObject (from PdfPage.Lines).
static bool LooksLikeHeading(IPdfTextObject run)
{
    return run.IsBold && run.FontSize >= 14f
        && !string.IsNullOrWhiteSpace(run.Contents);
}

PdfDocument pdf = PdfDocument.FromFile("invoice.pdf");
foreach (PdfPage page in pdf.Pages)
{
    foreach (IPdfTextObject run in page.TextChunks)  // IPdfTextObjectCollection
    {
        if (LooksLikeHeading(run))
        {
            System.Console.WriteLine(
                $"Page {run.PageIndex} heading \"{run.Contents}\" at {run.BoundingBox}");
        }
    }
}

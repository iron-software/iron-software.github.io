    Class SchemeColorValues

    Inheritance

    SchemeColorValues
    Namespace: IronPPT.Enums
    Assembly: IronPPT.dll
    Syntax
    public sealed class SchemeColorValues : Enum

    Reference a color by its slot in the theme rather than a fixed value with SchemeColorValues in IronPPT, so styling tracks the active theme. Text1 and Text2 map the body and secondary text colors, Background1 and Background2 map the page backgrounds, and Accent1 through Accent6 map the six theme accents. Hyperlink and FollowedHyperlink cover link colors. Use a scheme value when content should re-color automatically as the theme changes; use a preset color for a fixed shade. The add shape example shows colored shapes on a slide.

    var color = SchemeColorValues.Accent1;

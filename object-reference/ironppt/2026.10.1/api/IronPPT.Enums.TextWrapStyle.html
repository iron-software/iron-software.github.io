    public sealed class TextWrapStyle : Enum

    TextWrapStyle describes how an object is positioned relative to the text around it in IronPPT. Inline keeps the object in the text flow as a character would sit, Square and Tight wrap text around the bounding box or contour, and Behind and InFront place the object on a separate layer beneath or above the text. Choose the layering and wrap that gives a slide the intended depth.

    var wrapStyle = TextWrapStyle.Square;

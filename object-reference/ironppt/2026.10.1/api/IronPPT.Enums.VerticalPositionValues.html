    Raising or lowering run text relative to the baseline uses VerticalPositionValues. Baseline is the default position that leaves text on the line, Superscript lifts it for exponents and footnote markers, and Subscript drops it for chemical formulae and indices. Apply it to a run when a character needs to sit above or below the surrounding text. The add text how-to covers run-level formatting.

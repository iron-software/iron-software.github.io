    Page-number formatting comes from PageNumberStyle, which sets how slide or page numbers display. Arabic shows 1, 2, 3, the standard everyday choice, and Roman shows i, ii, iii for front-matter or formal numbering. None suppresses the number altogether. Pick the value that matches how a presentation should label its pages. The add slide how-to covers building and managing slides.

    var style = PageNumberStyle.Arabic;

    Pick the physical page dimensions a slide or printed document uses with PaperSize in IronPPT. Letter and Legal cover the common North American sizes, A4 and A5 cover the ISO sizes used elsewhere, and Custom signals that explicit width and height values are supplied instead of a named size. Choose the value that matches how the deck will be printed or exported. The add slide how-to walks through configuring a slide as you build the presentation.

    var size = PaperSize.A4;

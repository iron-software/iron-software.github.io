    Class SystemColorValues

    Inheritance
    System.Object
    SystemColorValues
    Namespace: IronPPT.Enums
    Assembly: IronPPT.dll
    Syntax
    public sealed class SystemColorValues : Enum

    Bind a slide color to an operating-system UI color with SystemColorValues in IronPPT, so the rendered element follows the viewer's theme rather than a fixed value. The common picks are Window and WindowText for surface and body text, Highlight and HighlightText for selection colors, ButtonFace and ButtonText for control surfaces, and Menu and MenuText for menu chrome. Many further entries cover captions, borders, and scrollbars for full OOXML fidelity.

    var sysColor = SystemColorValues.Window;

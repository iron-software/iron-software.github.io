    Syntax
    public sealed class Units : Enum

    Declaring which measurement a size or offset is expressed in uses Units, supplied as the measurementUnit argument on effect types such as Bevel and Shadow. pt (points) is the typographic unit common to slide measurements, inch, cm, and mm are the familiar page units, and Twips is the twentieth-of-a-point unit. EMU, the English Metric Unit, is the high-precision base unit the underlying presentation format stores internally. The add shape example places sized shapes on a slide.

    bevel.SetWidth(5, Units.pt);

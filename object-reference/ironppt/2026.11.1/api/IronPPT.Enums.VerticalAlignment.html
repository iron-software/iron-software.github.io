    Syntax
    public sealed class VerticalAlignment : Enum

    VerticalAlignment sets where text or content rests inside the vertical bounds of its container, such as a table cell or text frame. Top aligns to the upper inside edge, Middle centers between the edges, and Bottom aligns to the lower edge. It mirrors the shorter VerticalAlign enum value-for-value; pick whichever name the property you are setting expects. The add text how-to covers placing text in a frame.

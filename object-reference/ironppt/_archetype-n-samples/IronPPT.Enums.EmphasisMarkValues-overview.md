## Injected overview (Markdown)

Emphasis marks add the small dots that sit above or below run text for stress, and `EmphasisMarkValues` names the mark a run carries. `None` is the default and leaves text unmarked. `Dot` and `Circle` place a point or ring over each character, the usual choice for East Asian emphasis, while `UnderDot` drops the point below it and `Comma` uses a comma-shaped mark. The [add text how-to](https://ironsoftware.com/csharp/ppt/how-to/add-text/) covers styling run text on a slide.

```csharp
var mark = EmphasisMarkValues.Dot;
```

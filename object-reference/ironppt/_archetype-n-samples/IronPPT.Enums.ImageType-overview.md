## Injected overview (Markdown)

`ImageType` names the file format of a picture added to a slide. `Png` and `Jpeg` are the everyday raster choices, `Png` for sharp graphics with transparency and `Jpeg` for photos, while `Bmp`, `Gif`, and `Tiff` cover other raster formats. `Svg` carries vector artwork and `Wmf` the legacy Windows metafile. The [manage image how-to](https://ironsoftware.com/csharp/ppt/how-to/manage-image/) covers adding and working with pictures on a slide.

```csharp
var format = ImageType.Png;
```

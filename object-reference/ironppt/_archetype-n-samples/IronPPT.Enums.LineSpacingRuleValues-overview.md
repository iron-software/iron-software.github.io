## Injected overview (Markdown)

Use `LineSpacingRuleValues` to choose how a paragraph's line spacing is measured. `Auto` scales spacing as a multiple of the font size, the usual flexible choice that grows with larger text. `AtLeast` sets a minimum height that lines can exceed when content needs more room, and `Exact` pins lines to a fixed height that never changes. Pick the rule that fits how tightly a slide's paragraphs should sit. The [add text how-to](https://ironsoftware.com/csharp/ppt/how-to/add-text/) covers styling paragraphs on a slide.

```csharp
var rule = LineSpacingRuleValues.Auto;
```

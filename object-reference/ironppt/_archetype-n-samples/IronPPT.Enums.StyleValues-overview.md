## Injected overview (Markdown)

`StyleValues` identifies which kind of formatting a style definition targets in IronPPT. `Paragraph` covers block-level formatting and `Character` covers run-level text formatting, the two everyday choices, while `Table` applies to table presentation and `Numbering` applies to list numbering definitions. Use this when reading or assigning a style's category so the right formatting scope is applied to slide content.

```csharp
var kind = StyleValues.Paragraph;
```

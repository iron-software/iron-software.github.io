## Injected overview (Markdown)

Setting how text sits within its container runs through `TextAlignment` in IronPPT. In reading order, `Left` aligns text to the left edge and is the usual starting point, `Center` balances it around the middle, `Right` aligns to the right edge, and `Justified` stretches lines flush to both edges. Assign the value that fits the slide's layout when you add or style text. The [add text how-to](https://ironsoftware.com/csharp/ppt/how-to/add-text/) shows the alignment in a worked example.

```csharp
var alignment = TextAlignment.Center;
```

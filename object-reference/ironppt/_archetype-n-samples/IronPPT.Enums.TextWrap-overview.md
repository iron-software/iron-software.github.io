## Injected overview (Markdown)

Control whether surrounding text flows around an object with `TextWrap` in IronPPT. `None` is the default and lets text sit over or behind the object without wrapping, `Square` flows text around the object's bounding box, and `Tight` hugs the object's contour more closely. Pick the wrap that keeps a slide's text and graphics readable together. To work with the images this often applies to, see the [manage image how-to](https://ironsoftware.com/csharp/ppt/how-to/manage-image/).

```csharp
var wrap = TextWrap.Square;
```

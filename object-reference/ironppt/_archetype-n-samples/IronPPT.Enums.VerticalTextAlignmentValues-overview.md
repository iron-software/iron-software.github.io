## Injected overview (Markdown)

When text should align vertically within its frame, `VerticalTextAlignmentValues` selects the anchor. `Auto` lets the layout decide, `Top`, `Center`, and `Bottom` pin text to the upper edge, the middle, or the lower edge of the frame, and `Baseline` aligns runs of differing size along a shared baseline. Choose `Center` for the common boxed-caption look and `Baseline` when mixed font sizes must line up cleanly. The [add text how-to](https://ironsoftware.com/csharp/ppt/how-to/add-text/) covers positioning text in a frame.

    Class MeasurementUnit

    Enumeration representing various units of measurement.

    Inheritance
    System.Object
    MeasurementUnit
    Namespace: IronWord.Models.Enums
    Assembly: IronWord.dll
    Syntax
    public sealed class MeasurementUnit : Enum

    Express a size, offset, or distance in the unit a layout calls for by choosing a MeasurementUnit. Point is the typographic default used across most document measurements, Inch, Centimeter, and Millimeter cover the common physical units, Twip is the twentieth-of-a-point unit native to the underlying Word format, and EnglishMetricUnit is the fine-grained EMU used for drawing and image geometry.

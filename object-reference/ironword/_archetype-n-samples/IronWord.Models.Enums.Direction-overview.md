## Injected overview (Markdown)

Set the reading direction of text in a Word document with `Direction`. `LeftToRight` is the default flow used by Latin scripts and most layouts, while `RightToLeft` lays out runs for languages such as Arabic and Hebrew. Apply it when a paragraph or run needs the opposite orientation from the document default. The [add styled text example](https://ironsoftware.com/csharp/word/examples/add-style-text/) shows where run-level formatting is applied.

```csharp
var direction = Direction.RightToLeft;
```

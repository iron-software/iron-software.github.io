## Injected overview (Markdown)

Position content across the horizontal axis with `HorizontalAlignment`. `Left` aligns to the left edge and is the usual default for body content, `Center` centers within the available width, and `Right` pushes content to the right edge. Reach for it when placing an image, shape, or other element sideways within its container. The [add image example](https://ironsoftware.com/csharp/word/examples/add-image/) shows where placement is configured.

```csharp
var alignment = HorizontalAlignment.Center;
```

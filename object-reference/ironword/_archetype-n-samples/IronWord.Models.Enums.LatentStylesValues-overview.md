## Injected overview (Markdown)

Reference a built-in Word style by name with `LatentStylesValues`. The enumeration names Word's standard latent styles so you can target one without typing its string. Everyday choices include `Normal`, the body paragraph styles such as `Body_Text`, `Title`, `Quote` and `Intense_Quote`, `Hyperlink`, and the many built-in table styles like `Colorful_Grid` and its accent variants. Underscores in a member name stand in for the spaces in Word's display name. The [add styled text example](https://ironsoftware.com/csharp/word/examples/add-style-text/) shows how styling is applied.

## Injected overview (Markdown)

Pick the geometry of a drawing object by setting a `ShapeType`, which names the preset shapes Word can render. Everyday choices include `Rectangle`, `RoundRectangle`, `Ellipse`, `Triangle`, and `Line`, while the enum also covers wide families of arrows, stars, callouts, and flowchart symbols for diagram work. The [add image guide](https://ironsoftware.com/csharp/word/how-to/add-image/) covers placing visual objects in a document.

```csharp
var kind = ShapeType.Rectangle;
```

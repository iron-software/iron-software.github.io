## Injected overview (Markdown)

Position paragraph text against the page margins by choosing a `TextAlignment` value on a paragraph or text style. `Left` aligns to the left margin and is the everyday default for body copy, `Center` balances a heading or caption between the margins, `Right` flushes text to the right edge, and `Justified` stretches each line to both margins for a clean block. The [add text guide](https://ironsoftware.com/csharp/word/how-to/add-text/) and the [style text guide](https://ironsoftware.com/csharp/word/how-to/add-style-text/) show alignment applied in context.

```csharp
paragraph.Alignment = TextAlignment.Center;
```

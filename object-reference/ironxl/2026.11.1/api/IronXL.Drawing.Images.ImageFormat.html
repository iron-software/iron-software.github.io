    Class ImageFormat

    Enum that represents type of the loaded image.

    Inheritance
    System.Object
    ImageFormat
    Namespace: IronXL.Drawing.Images
    Assembly: IronXL.dll
    Syntax
    public sealed class ImageFormat : Enum

    ImageFormat declares the encoding of an image when IronXL inserts one into a worksheet, passed to WorkSheet.InsertImage. PNG suits lossless graphics and screenshots, JPEG fits photographs where smaller files matter, and BMP, GIF, and TIFF cover uncompressed, animated, and high-resolution sources. The worksheet images how-to and the add and extract images example show inserting an image.

    worksheet.InsertImage(bytes, ImageFormat.PNG, 1, 1, 4, 6);

    Class FillPattern

    The enumeration value indicating the style of fill pattern being used for a cell format.

    Inheritance
    System.Object
    FillPattern
    Namespace: IronXL.Styles
    Assembly: IronXL.dll
    Syntax
    public sealed class FillPattern : Enum

    Set FillPattern to choose the shading style applied behind a cell's contents, assigned to the FillPattern property of a range or cell Style. NoFill is the default that leaves the cell unshaded, and SolidForeground fills it with a flat foreground color. The remaining values give textured patterns such as FineDots, SparseDots, ThickForwardDiagonals, and Bricks, along with further dot, diagonal, and band variations. The background and pattern color how-to shows the property in use.

    worksheet["A1"].Style.FillPattern = FillPattern.SolidForeground;

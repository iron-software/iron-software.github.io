## Injected overview (Markdown)

Trouble with the material handed to the OCR engine raises this exception, thrown when an image, PDF, or stream supplied as input cannot be opened, decoded, or read as a supported format. Check that the file exists and is readable, that its format is one IronOCR accepts, and that a stream sits at its start before retrying. It derives from `Exception`. The [input images how-to](https://ironsoftware.com/csharp/ocr/how-to/input-images/) lists the supported sources.

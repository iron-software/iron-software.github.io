## Injected overview (Markdown)

The `AFRelationship` enumeration in IronPDF declares the relationship between an embedded file and a PDF/A-3 document, which matters most for ZUGFeRD and Factur-X e-invoicing workflows.

It belongs to the `IronPdf` namespace and exposes 5 values: `Unspecified` (default), `Alternative`, `Source`, `Data`, and `Supplement`. Each value tells PDF/A readers how the attached XML or supporting file relates to the visual document.

See [Export PDF/A Format Docs in C#](https://ironpdf.com/how-to/pdfa/) for the full PdfAOptions configuration.

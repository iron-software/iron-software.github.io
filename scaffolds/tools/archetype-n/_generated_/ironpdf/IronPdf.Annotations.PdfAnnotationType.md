## Injected overview (Markdown)

The `PdfAnnotationType` enumeration in IronPDF identifies the kind of annotation attached to a page, covering the full set of 29 annotation subtypes defined by the PDF specification.

Part of the `IronPdf.Annotations` namespace, common values include `Text`, `Highlight`, `Link`, `Stamp`, `FreeText`, and `FileAttachment`, with markup variants such as `Underline`, `StrikeOut`, and `Squiggly` rounding out the set.

Use this enum when inspecting existing annotations or filtering them by type. To add or edit annotations programmatically, see [Add & Edit Annotations](https://ironpdf.com/how-to/annotations/).

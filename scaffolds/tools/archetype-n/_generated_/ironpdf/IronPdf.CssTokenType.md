## Injected overview (Markdown)

`CssTokenType` identifies the category of a CSS token encountered during stylesheet parsing in IronPDF. `Declaration` is the primary value, representing a CSS property-value pair. `Comment` marks comment blocks, `Delimiter` covers punctuation and separator characters, and `Other` captures any token that does not fit a named category. See the [IronPDF documentation](https://ironpdf.com/docs/) for CSS handling details.

## Injected overview (Markdown)

The `BarcodeEncoding` enumeration in IronPDF declares the supported barcode symbologies that can be stamped onto a PDF page.

Part of the `IronPdf.Editing` namespace, it includes `Code128`, `QRCode`, and `Code39` (3 total).

Pass a member to a `BarcodeStamper` when adding scannable codes to a generated document. See [Add Barcodes in HTML to PDF](https://ironpdf.com/examples/barcode-htmltopdf/) for typical usage in C# rendering.

## Injected overview (Markdown)

The `ImageType` enumeration in IronPDF declares the output image file format when rasterizing PDF pages.

Part of the `IronPdf.Imaging` namespace, it includes `Png`, `Jpeg`, `Tiff`, `MultiPageTiff`, `Gif`, `Bitmap`, and `Default` (7 total).

Pass a member to `RasterizeToImageFiles` or related extraction methods to control the saved format. See [Image from PDF](https://ironpdf.com/how-to/rasterize-pdf-to-images/) for typical usage in C# rendering.

## Injected overview (Markdown)

The `NaturalLanguages` enumeration in IronPDF identifies the document language tag emitted for PDF/UA accessibility and screen-reader support.

Part of the `IronPdf` namespace, it covers 259 entries spanning base languages such as `English`, `French`, `Spanish`, `Chinese`, and `Japanese`, plus locale-specific variants like `English_UnitedKingdom` or `Spanish_Mexico` that map directly to BCP-47 tags.

See [PDF/UA language settings](https://ironpdf.com/how-to/pdfua/#language-settings) for the assignment pattern on `PdfDocument`.

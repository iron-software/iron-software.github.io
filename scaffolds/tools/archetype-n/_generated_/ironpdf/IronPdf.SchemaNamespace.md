## Injected overview (Markdown)

The `SchemaNamespace` enumeration in IronPDF declares the PDF/A schema NamespaceURI written into XMP metadata when an XML payload is embedded for e-invoicing compliance.

It belongs to the `IronPdf` namespace and exposes five values: `facturX` (default), `Zugferd1`, `Zugferd2`, `ferd`, and `etda`. Each maps to a published standard for the embedded XML.

See [Export PDF/A Format Docs in C#](https://ironpdf.com/how-to/pdfa/) for ZUGFeRD and Factur-X examples.

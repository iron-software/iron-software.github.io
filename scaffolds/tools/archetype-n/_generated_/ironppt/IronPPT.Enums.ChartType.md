## Injected overview (Markdown)

`ChartType` selects which kind of chart to render on a slide. `Bar` plots categories as bars and is the common default for comparisons, `Line` traces values over a sequence for trends, and `Pie` shows parts of a whole as proportional slices. Pass the value that fits the data you are presenting when you build a chart.

```csharp
var chartType = ChartType.Bar;
```

## Injected overview (Markdown)

`LatentStylesValues` names the built-in document styles a presentation knows about, the named formats that map back to Word-style definitions. `Normal` is the base body style, `heading_1` through `heading_9` cover the heading levels, and `No_Spacing` drops paragraph spacing. List styles (`List`, `List_Bullet`, `List_Number`) format bulleted and numbered content, while `caption`, `header`, `footer`, and `page_number` name page-furniture styles. Reach for a value when you need to reference one of these named styles by identity. The [paragraph style example](https://ironsoftware.com/csharp/ppt/examples/paragraph-style/) shows styling paragraphs.

```csharp
var style = LatentStylesValues.heading_1;
```

## Injected overview (Markdown)

Choose how a slide or page reads, wide or tall, with `PageOrientation` in IronPPT. `Landscape` lays the surface out horizontally, the usual choice for on-screen presentations, while `Portrait` makes it taller than it is wide for printed handouts and document-style layouts. Set the value when you configure a slide so its dimensions and content flow match the intended output. The [add slide how-to](https://ironsoftware.com/csharp/ppt/how-to/add-slide/) shows where slide configuration fits into building a deck.

```csharp
var orientation = PageOrientation.Landscape;
```

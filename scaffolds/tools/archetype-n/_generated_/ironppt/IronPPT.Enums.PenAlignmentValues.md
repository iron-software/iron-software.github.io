## Injected overview (Markdown)

Control where a shape outline sits relative to its edge with `PenAlignmentValues` in IronPPT. `Center` straddles the line stroke across the boundary so half falls inside and half outside, while `Inset` pulls the whole stroke inward so it stays within the shape bounds. Choose the value when you style a border so the outline aligns the way the design calls for. The [add shape example](https://ironsoftware.com/csharp/ppt/examples/add-shape/) shows shapes being placed on a slide.

```csharp
var alignment = PenAlignmentValues.Center;
```

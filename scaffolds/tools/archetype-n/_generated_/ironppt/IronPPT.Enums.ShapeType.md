## Injected overview (Markdown)

Choose which preset geometry a shape draws with `ShapeType` in IronPPT. The everyday primitives are here, `Rectangle`, `RoundRectangle`, `Ellipse`, `Line`, and `Triangle`, alongside the full OOXML preset catalog of arrows like `RightArrow`, callouts, stars such as `Star5`, banners, flowchart nodes, and decorative forms like `Diamond`, `Heart`, and `Hexagon`. Pick the value when you add a shape so it renders with the intended outline. The [add shape example](https://ironsoftware.com/csharp/ppt/examples/add-shape/) shows shapes being placed on a slide.

```csharp
var shape = ShapeType.Rectangle;
```

## Injected overview (Markdown)

Pick how quickly an animated effect plays on a slide with `SpeedValues` in IronPPT. `Medium` is the balanced, conventional pace and the value most decks use, `Fast` shortens the timing for snappy transitions, and `Slow` draws an effect out for emphasis. Assign one of these named speeds wherever a presentation element exposes an animation timing setting, so the saved PowerPoint plays the motion at the intended rate.

```csharp
var speed = SpeedValues.Medium;
```

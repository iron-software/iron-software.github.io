## Injected overview (Markdown)

Control whether a run of text carries a strikethrough line with `StrikValue` in IronPPT. `NoStrike` is the unmarked default for ordinary text, `SingleStrike` draws one line through the characters, and `DoubleStrike` draws two for stronger emphasis. Set this on the text styling that decorates a run when you author or edit slide content, and IronPPT records the corresponding strikethrough in the saved PowerPoint. To work with the runs this applies to, see the [add text how-to](https://ironsoftware.com/csharp/ppt/how-to/add-text/).

```csharp
var strike = StrikValue.SingleStrike;
```

## Injected overview (Markdown)

Pick a theme font slot with `ThemeFontValues` when text should follow the presentation theme instead of a hard-coded typeface, so a theme change restyles the slides. The major slots (`MajorAscii`, `MajorBidi`, `MajorEastAsia`, `MajorHighAnsi`) are the heading family; the minor slots (`MinorAscii`, `MinorBidi`, `MinorEastAsia`, `MinorHighAnsi`) are the body family. Within each pair, `Ascii` covers Latin text, `HighAnsi` extended Latin, `EastAsia` CJK scripts, and `Bidi` right-to-left scripts. The [add text how-to](https://ironsoftware.com/csharp/ppt/how-to/add-text/) covers styling slide text.

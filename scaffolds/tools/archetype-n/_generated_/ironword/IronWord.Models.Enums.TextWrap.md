## Injected overview (Markdown)

Control how surrounding paragraph text flows around a placed image or shape by setting a `TextWrap` value. `None` keeps the object on its own line with no wrapping, `Square` runs text around a rectangular boundary so copy fills the space beside the object, and `Tight` hugs the object's contour more closely for irregular outlines. The [add image guide](https://ironsoftware.com/csharp/word/how-to/add-image/) covers placing and wrapping pictures in a document.

```csharp
image.TextWrap = TextWrap.Square;
```
